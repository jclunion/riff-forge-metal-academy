# RiffForge Academy

Plateforme interactive d'apprentissage de la guitare metal, 100 % autonome en HTML/CSS/JavaScript.

## Fonctionnalités

- **Tableaux de bord par apprenant** avec suivi détaillé de la progression BPM et des compétences.
- **Catalogue de cours** filtrable par catégories et accordages.
- **Lecteur de cours interactif** avec emplacements pour leçons vidéo (multi-angles, chapitres, import vidéo local).
- **Tablature interactive** avec manche synchronisé et moteur audio Web Audio (métronome + guitare synthétisée).
- **Quiz de validation** intégrés.

## Déploiement sur Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/import?s=https://github.com/jclunion/riff-forge-metal-academy)

1. Importez le dépôt **`jclunion/riff-forge-metal-academy`** sur [Vercel](https://vercel.com/new).
2. Laissez les paramètres par défaut (**Framework Preset** : `Other`, **Build Command** : vide, **Output Directory** : `.`).
3. Cliquez sur **Deploy** : la configuration est gérée via [`vercel.json`](vercel.json).

## Utilisation en local

Ouvrez simplement [`index.html`](index.html) dans un navigateur moderne.
